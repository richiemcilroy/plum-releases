# Plum for Mac

Official signed and notarized macOS downloads for [Plum](https://www.plum.so).

This repository contains public release files and release metadata only.

Plum is currently a managed alpha. Use copied test data and keep your original files. macOS 26.2 or later and Apple silicon are required.

Download the current release from [plum.so](https://www.plum.so/download). Release notes and checksums accompany each version.
